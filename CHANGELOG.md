# Changelog

## 1.0.0 — Versionsbasis

Gemeinsame Ausgangsversion für Frontend und Backend. Der zugehörige Git-Tag
`v1.0.0` muss einmalig auf dem gewünschten Ausgangscommit auf `main` gesetzt
werden; siehe [Release-Anleitung](docs/releases.md).

Künftige Einträge werden von semantic-release aus den Commits seit dem letzten
Release-Tag erzeugt.
